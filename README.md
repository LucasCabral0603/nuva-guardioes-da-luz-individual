# NUVA — Guardiões da Luz

## Sprint 04 — Integração com Backend e API REST

Projeto individual desenvolvido para a Sprint 04 da FIAP.

O NUVA — Guardiões da Luz é uma plataforma voltada à sustentabilidade, que transforma ações sustentáveis em recompensas e incentiva a participação dos usuários.

Nesta Sprint 04, o projeto recebeu integração entre o Front-End em React e uma API REST desenvolvida em Java com Spring Boot, utilizando banco de dados Oracle.

## Tecnologias

### Front-End

- React
- Vite
- TypeScript
- Tailwind CSS
- React Router DOM
- React Hook Form

### Back-End

- Java 17
- Spring Boot
- API REST
- JDBC
- Oracle Database

## Funcionalidades da Sprint 04

- Integração do React com API REST em Java
- Consulta de usuários através da API
- Cadastro de usuários através do Front-End
- Persistência dos dados no banco Oracle
- Consumo de dados utilizando `fetch`
- Tipagem dos dados utilizando TypeScript
- Interface responsiva com Tailwind CSS
